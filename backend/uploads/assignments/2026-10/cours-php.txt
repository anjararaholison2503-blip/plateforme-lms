Cours introduction programmation PHP : les variables stockent des donnees, les fonctions regroupent du code reutilisable, les boucles repetent des instructions, les tableaux stockent plusieurs valeurs, les classes definissent des objets, l heritage reutilise du code existant, les interfaces definissent des contrats, les namespaces evitent les collisions, les exceptions gerent les erreurs. 
En PHP, une variable commence par un dollar. Les operateurs arithmetiques incluent plus, moins, fois, divise. Les operateurs de comparaison incluent egal, different, superieur, inferieur. Les structures conditionnelles utilisent if, else, elseif et switch. Les boucles incluent for, while, do-while et foreach.
